# Smart Metro Footfall Prediction & Crowd Analysis System

An AI/ML-based metro passenger flow forecasting and crowd analysis project that combines **time series forecasting**, **deep learning**, **weather-aware prediction**, and **CCTV crowd density analysis** to estimate and visualize metro station footfall trends.

This project focuses on predicting hourly metro passenger footfall using multiple machine learning and deep learning approaches such as:

- ARIMA
- SARIMA
- LSTM
- 1D CNN
- Random Forest
- Linear Regression

The system also includes:
- Dataset preprocessing
- Hourly footfall estimation
- CCTV crowd density visualization
- Passenger flow analytics
- Weather-integrated forecasting

---

# 📌 Project Objectives

- Predict metro station passenger footfall accurately
- Analyze hourly crowd density trends
- Compare classical ML vs deep learning forecasting models
- Use weather conditions as external influencing features
- Generate actionable insights for metro operations and crowd management

---

# 🚀 Features

- 📈 Time-series forecasting using ARIMA & SARIMA
- 🧠 Deep learning models using LSTM & 1D CNN
- 🌦 Weather-aware passenger flow prediction
- 📹 CCTV metadata-based crowd density analysis
- 📊 Visualization of daily/hourly trends
- 🔍 Model comparison using:
  - R² Score
  - MAPE
  - Prediction Accuracy
- 🗂 Automatic hourly dataset generation from daily data

---

# 🧠 Machine Learning & Deep Learning Models

| Model | Purpose |
|---|---|

| Random Forest | Non-linear footfall prediction |
| ARIMA | Time-series forecasting |
